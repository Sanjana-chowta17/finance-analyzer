# Finance Analyzer

A full-stack personal finance application that helps users track transactions, analyze spending, import bank statements, and get AI-powered financial insights.

## Tech Stack

### Frontend
- React
- Vite
- Axios
- Recharts

### Backend
- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Spring Security
- JWT Authentication

### AI
- Google Gemini
- AI-powered transaction categorization
- Spending insights
- Finance Q&A assistant
